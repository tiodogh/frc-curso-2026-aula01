Projeto: Entrada e Saída Digital na roboRIO.

Objetivo

Controlar um LED utilizando um botão conectado à roboRIO.

Componentes

- roboRIO
- LED
- Botão

Programação

- Linguagem: Java
- Biblioteca: WPILib 2026
- DigitalInput: canal 0
- DigitalOutput: canal 1

Funcionamento

O botão envia um sinal digital para a roboRIO, que controla o LED.

Código utilizado:

"led.set(botao.get());"

Também foi testada a inversão lógica com o operador NOT.
